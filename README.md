# Mi Primer Repo

## 📝 Descripción
Este es mi primer proyecto subido a GitHub. Consiste en una aplicación web básica de "Hola Mundo" realizada como tarea de clase para aprender a gestionar repositorios.

## 🚀 Lenguaje Utilizado
* HTML5 / JavaScript

## 🛠️ Cómo Ejecutar el Proyecto
1. Descarga el repositorio o clónalo.
2. Abre el archivo `index.html` en cualquier navegador web (Chrome, Edge, Firefox).
